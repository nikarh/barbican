# Security

barbican decides who may reach a server, so a way to get an address past its bans, to get someone else's address
banned, or to change its decisions without access to its UI or edge API is a security issue.

Please report it privately, through [GitHub's vulnerability reporting](https://github.com/nikarh/barbican/security/advisories/new),
not in a public issue. Include the log lines or requests involved and how to reproduce it.
