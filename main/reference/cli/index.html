Command line

barbican

Section titled “barbican”
Option
-c, --config <path> The configuration file; by default $BARBICAN_CONFIG, or /etc/barbican/config.toml
--dry-run Decide and record, but leave the firewall alone (as firewall.enabled = false)
-h, --help The help
  • Running: the agent logs to standard error, at the info level unless RUST_LOG says otherwise (RUST_LOG=debug, or per module). Under systemd (journalctl -u barbican) it tells systemd it is ready once its firewall table is in place.
  • parse: parsers traefik, sshd, authelia. Prints the address, the kind of event and what happened for each line understood, and how many were. See Checking a parser.
  • replay and import: see Importing old logs.
  • edge-fingerprint: reads the certificate the agent made on its first start with [edge]; it doesn’t make one.
  • ui-proxy and healthcheck: what the container image runs, and only supported in a container; see The UI container. It refuses to start without --trusted-proxy, and warns when it doesn’t seem to run in a container. /healthz answers anyone (the healthcheck asks it); everything else only the trusted proxy.

barbican-vlogs

Section titled “barbican-vlogs”

Streams a VictoriaLogs query’s history as <time> <message> lines, oldest first, on standard output, for barbican import.

Option Default
--url <url> http://127.0.0.1:9428 The VictoriaLogs
--since <time> 365d From: an RFC 3339 time, a date (2026-02-12) or an age (30d, 12h)
--until <time> now To, the same way
--window <hours> 6 The time range of one request
--parallel <n> 4 Requests at a time

barbican-edge, barbican-edge-ipset

Section titled “barbican-edge, barbican-edge-ipset”

barbican-edge-ipset takes the same commands; its configuration is /jffs/barbican/barbican.conf by default. The options of the configuration file are in Configuring an edge.
